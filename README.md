# Zenith Hackers Intelligence

Responsive static website with a searchable educational blog containing 1,000 individually addressable article pages across ten categories.

## Deployment
- GitHub Actions workflow: `.github/workflows/pages.yml`
- The workflow generates all blog pages at build time using `scripts/generate_blog.py`, then deploys the static site to GitHub Pages.
- The blog index supports search, category filtering and pagination.
- Sitemap and robots.txt are generated during the build.

## Important
- The blog articles are educational templates and should be reviewed and fact-checked before publication; they are not 1,000 independently researched reports.
- The contact link opens the visitor's email application; no server-side contact form is configured.
- The homepage chatbot and community UI are demonstrations, not a production support system or shared publishing backend.
- Confirm business contact details, legal permissions, privacy disclosures, image assets and applicable requirements before launch.
- Only perform cybersecurity work on systems you own or have explicit written authorization to test. Never request passwords, private keys or recovery phrases.
